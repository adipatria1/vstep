VolStep Mobile Client

Aplikasi native Android untuk memonitor & mengontrol VolStep Futures Bot di Binance Testnet & Real.

Petunjuk Koneksi ke Server Bot:

  1. Jalankan bot di PC / Laptop / VPS Anda: ./run.sh.
  2. Pastikan HP Anda terhubung ke WiFi yang sama dengan PC (atau gunakan IP VPS).
  3. Klik tombol Server IP di pojok kanan atas aplikasi.
  4. Masukkan alamat IP PC Anda (contoh: http://192.168.1.15:5050).
